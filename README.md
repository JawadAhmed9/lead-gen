# AI-Powered B2B Lead Generation Platform

> An end-to-end AI sales automation platform for discovering, enriching, scoring, and organizing B2B decision-makers.

## Overview

Traditional B2B prospecting requires sales teams to manually search for companies, identify relevant decision-makers, collect contact information, and determine whether each prospect matches their Ideal Customer Profile (ICP).

This project automates that workflow using APIs, backend pipelines, LLM-based scoring, and a web dashboard.
